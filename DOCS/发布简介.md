# 发布简介

## 一句话

**一块不用连电脑的机械臂示教录制板：手掰一遍，存进板子，一键回放。**

## 短介绍（约 300 字，可直接放 GitHub Release / 项目首页）

基于 STM32F407VET6 的机械臂**离线示教录制**控制器。双路 1 Mbit/s CAN 同时驱动 16 台
RobStride 关节电机，100 Hz MIT 控制 + 解析重力补偿，配 1.54" 屏与 4 个按键，全程中文界面。

现场使用只需要三步：手掰机械臂（零力矩 + 逐轴阻尼）→ 轨迹边录边写板载 W25Q64（5 槽 × 60 秒，
掉电不丢）→ 一键回放（CSP 或 MIT 两种方式，可设轮数与轮间停留）。

不需要 ROS、不需要工控机、不需要连网：上电即用，适合现场快速示教、反复验证动作、拍摄演示。
工程同时提供串口命令行，可查看 16 轴角度/力矩/温度、切换控制模式、核对阻尼表、打印重力前馈、
抓取原始 CAN 帧，便于二次开发与排障。

## 亮点

- **零力矩示教**：拖动时只保留可调阻尼，手感最接近"直接拖"，录下来的就是人手的动作；
- **边录边存**：录制过程中直接写 W25Q64，60 秒轨迹不占 RAM，掉电不丢，开机自动载入；
- **两种回放**：CSP（电机内部位置环 + 逐轴安全限流）或 MIT（kp/kd 可调的柔性跟踪）；
- **安全到每一轴**：电流限幅按各关节 `max_safe_torque` 换算（rs-02 8.11 A、rs-05 2.26 A、夹爪 0.38 A）；
- **重力补偿可用**：与 pinocchio `rnea` 对照误差 < 1e-4 N·m，可切换"重力补偿拖动"；
- **中文屏幕 + 增量刷新**：自建点阵字库，录制时只有计时在动，界面不闪。

## 适用对象

- 需要**快速示教**双 7 轴机械臂动作的现场调试；
- 想在没有 ROS 环境的板子上做 RobStride 电机控制/录制的开发者；
- 做机械臂教学演示、动作录制回放实验的同学。

## 技术栈

`STM32F407 + 裸机 1 ms 协作式调度` · `bxCAN 双路 1 Mbit/s` · `ST7789 1.54"` · `W25Q64` ·
`RobStride 协议（29 位扩展帧）` · `arm-none-eabi-gcc` · `OpenOCD / WCH-Link` · `MIT / CSP 控制`

## 快速体验

```bash
make -j && ./tools/flash.sh auto build/firmware.elf
# 屏幕上：录制 → 开始录制 → 手掰 → 停止录制 → 回放
```
